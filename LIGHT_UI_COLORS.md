# Light UI Design System Colors

Based on Apple iOS Light Mode System Colors guidelines.

## Background Colors
- **Primary Background (`tsBackground`)**: `#F2F2F7` (systemGroupedBackground) 
  Used for the very back layer of the app interface.
- **Card/Secondary Background (`tsCard`)**: `#FFFFFF` (secondarySystemGroupedBackground)
  Used for elevated cards, content modules, buttons, list rows.

## Label Colors
- **Primary Text (`tsLabel`)**: `#000000` (label)
  Used for primary titles, headings, regular text that needs highest contrast.
- **Secondary Text (`tsSecondary`)**: `#8E8E93` (systemGray / secondaryLabel)
  Used for subtitles, hints, meta-information.

## Fill Colors & Borders
- **Inputs (`tsInputBg`)**: `#787880` at `12%` opacity (tertiarySystemFill)
  Used for text field backgrounds, search bars.
- **Borders/Dividers (`tsBorder`)**: `#3C3C43` at `29%` opacity (separator)
  Used for lines dividing content, borders outlining unselected cards.

## Semantic Colors
- **Primary Accent (`tsAccent`)**: `#007AFF` (systemBlue)
  Used for primary action buttons, selected states, progress bars.
- **Secondary Accent (`tsAccentTeal`)**: `#5AC8FA` (systemTeal)
  Used for alternate gradients and highlighted accents.
