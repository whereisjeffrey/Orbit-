## Jump Cut Sequence (for the "runaround" section)

Messages that appear in the rapid-fire Google Translate demo:

1. User types: **"I need to send one message"**
2. Reply appears: **"Tá, mas por quê tanta demora?"** (OK but why did that take so long?)
3. Translation shows: **"My thumbs hurt"**
4. User types: **"This is exhausting"**
5. Final message: **"I give up"**

Each message IS the experience of using Google Translate. The joke escalates.
